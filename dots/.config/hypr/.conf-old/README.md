# Legacy Hyprland configuration

These former Hyprlang `.conf` files were moved here on 2026-11-15 after checking
the Lua entry point and runtime helpers. Their relative folders are preserved.
Active settings now use the `.lua` files outside this directory.

The lock screen, idle daemon and desktop portal still use their `.conf` files
outside this directory. The old Matugen Hyprland color template writes its
legacy output here so it does not recreate an unused active-looking file.
